# Contributing — ethical open-source loop

Lesson learned (Aug 2025 mass auto-PRs → appeal): quality > quantity.

## Rules
1. 1 issue at a time. Request assignment, wait for maintainer.
2. One hand-authored PR per issue. Lint + tests + migration where needed.
3. No automation, no farm. If maintainer says stop, respect fully.
4. Co-authored PRs: real pair work only, with `Co-authored-by:` trailer.
5. Link issue, repro, fix, verification in every PR body.

This is how we earn Pull Shark tiers + Pair tiers legitimately.
