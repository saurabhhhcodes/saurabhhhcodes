## Q1: How do I run the Calle phone-call recipe locally?
A: Install Calle CLI, `calle auth login`, copy `.env.example`, run demo in `awesome-phone-call-agents/demo`. Verify with `calle calls status`. Post logs if stuck.

## Q2: Why does my profile README stats action fail?
A: Forked profile actions need `GH_TOKEN` with repo scope. Check Actions → failed run → secrets. Re-run after adding token.

## Q3: How do I get assigned to a GSSoC issue without spamming?
A: Comment once: skills + plan + ETA. Wait for maintainer assign. One issue at a time. Link prior merged PR as proof.
