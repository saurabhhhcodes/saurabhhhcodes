# Security Policy

## Supported
Profile repo + docs. Security fixes prioritized.

## Reporting
Please do NOT open public issues for vulnerabilities.
Contact via GitHub Security Advisories (private) on this repo.

We aim to respond within 72h, fix + credit reporter, and request CVE / GitHub Advisory credit where eligible (path to Security Advisory Credit highlight badge).

## Scope
- Secrets: never commit tokens. Secret scanning + push protection enabled.
- Dependencies: portfolio-website deps updated monthly.
